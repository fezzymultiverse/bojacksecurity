# Contributing
Small, surgical changes please. One change per merge request, and explain what it does and how you tested it.
- The app is one file: `www/index.html`. Keep it dependency-free.
- Never log, store or transmit keys, passwords or plaintext file contents.
- Keep the black and neon purple theme, and keep light mode working.
- Update `CHANGELOG.md` and `docs/HANDOVER.md` with every change.
- Report security issues privately, see `SECURITY.md`.
